# ajr-alves.github.io

Personal site of Alexandre Alves: research and thoughts on machine learning and AI agents.

Plain static HTML and CSS served by GitHub Pages, with no build step.

- `index.html`: home page
- `thesis/`: master's thesis summary page
- `files/`: thesis PDF and CV
- `assets/`: stylesheet, theme toggle script and the symbol

Light and dark themes follow the visitor's system setting, and the toggle remembers their choice. The font is Inter Tight, loaded from Google Fonts.
